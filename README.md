# Basic Calculator

A small browser-based calculator built with HTML, CSS, and vanilla JavaScript.

## Features

- Add, subtract, multiply, and divide
- Enter decimal and percentage values
- Clear the current input or delete the last character
- Format numeric results for display

## Run

Open `index.html` in a modern web browser. No package installation or build step is required.

## Files

- `index.html` — calculator page
- `style.css` — layout and visual styling
- `script.js` — button generation and calculator logic
